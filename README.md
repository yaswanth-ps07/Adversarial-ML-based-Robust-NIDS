# Improving the Robustness of Deep Learning-Based Network Intrusion Detection Against Adversarial Attacks

## Problem statement
Deep-learning NIDS models can classify benchmark network flows accurately yet remain vulnerable to deliberately chosen small input perturbations. This project measures that weakness using bounded feature-space FGSM and PGD attacks and tests whether adversarial training improves robustness.

## Objectives
Build a binary NORMAL-vs-ATTACK DNN, evaluate clean performance, generate bounded adversarial examples, measure degradation and attack success, train a robust model with clean + adversarial training samples, compare both models, and demonstrate the experiment in Streamlit.

## Architecture
`CIC-IDS2017 → cleaning → stratified train/validation/test split → training-only imputation/scaling → DNN → clean evaluation → FGSM/PGD → adversarial training → robust DNN → comparison/dashboard`

## Dataset
The project uses CIC-IDS2017 from the Canadian Institute for Cybersecurity at the University of New Brunswick. It is suitable because it is a public labelled intrusion-detection benchmark containing benign traffic, multiple attack families, and flow-level features that can be used by ML models. The project uses binary labels: `BENIGN=0`, all attack labels `=1`.

Dataset files are not included because they are large. Follow `data/README.md` and place the official MachineLearningCSV files under `data/raw/`.

## Technologies
Python 3.11/3.12, NumPy, pandas, scikit-learn, PyTorch, Matplotlib, SHAP, Streamlit, joblib and pytest.

## Installation on macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Dataset setup
Download CIC-IDS2017 from the official UNB CIC dataset page described in `data/README.md`. Extract the labelled MachineLearningCSV files to `data/raw/`.

## Baseline training
```bash
python src/train.py
```
This validates the dataset, cleans names, removes duplicates, maps labels to binary classes, converts usable features to numeric, handles infinity/missing values, performs a stratified split, fits medians and `StandardScaler` only on training data, saves preprocessing artifacts, and trains the DNN with Adam and early stopping.

## Evaluation and attacks
```bash
python src/evaluate.py
```
This evaluates clean data and bounded feature-space FGSM/PGD examples. Attack success rate is the fraction of samples that were originally classified correctly but become incorrect after the adversarial perturbation.

## Adversarial training
```bash
python src/adversarial_training.py
python src/evaluate.py
```
A fixed fraction of training samples is attacked with FGSM and appended to clean training samples. The robust model uses the same architecture for a fair comparison.

## Complete pipeline
```bash
python run_pipeline.py
```

## Explainability
After training:
```bash
python src/explain.py
```
This creates `results/metrics/shap_feature_importance.csv` using mean absolute SHAP values. It is intentionally limited to feature ranking rather than a research-level XAI system.

## Dashboard
```bash
streamlit run app.py
```
Sections: Home, Dataset, Baseline Model, Adversarial Attack, Robust Model, Comparison and Prediction. The dashboard reads metrics produced by actual executions; it contains no hard-coded accuracy claims.

## Results
After execution, `results/metrics/comparison.csv` contains Accuracy, Precision, Recall, F1, False Positive Rate and Attack Success Rate for available scenarios. Figures include confusion matrices, training histories, accuracy/F1 comparisons and attack-success comparison. No experimental metric is bundled unless generated by an actual run.

## Major modules
- `dataset.py`: finds, loads and validates official CSV files.
- `data_preprocessing.py`: leakage-safe cleaning, splitting, imputation and scaling.
- `model.py`: understandable 128→64→32 PyTorch DNN.
- `train.py`: baseline training, early stopping and artifact saving.
- `adversarial_attacks.py`: bounded FGSM and PGD in scaled feature space.
- `adversarial_training.py`: augments training data and trains the robust DNN.
- `evaluate.py`: computes metrics, reports, confusion matrices and comparison CSV/charts.
- `explain.py`: simple SHAP feature-importance ranking.
- `app.py`: Streamlit demonstration UI.

## Reproducibility
The project uses seed 42 for Python, NumPy, PyTorch and data splitting. Saved artifacts include models, scaler, training medians, feature names, dataset metadata, train/validation/test arrays, histories and metrics.

## Limitations
FGSM and PGD operate on normalized flow-feature vectors. Although perturbations are bounded, not every adversarial vector is guaranteed to correspond to a physically realizable network flow or packet trace. Therefore results measure feature-space model robustness, not a real packet-generation attack. CIC-IDS2017 is also a benchmark collected in 2017 and cannot represent every modern network environment.

## Future scope
Add semantic constraints for mutable network features, test transfer attacks, compare another public IDS dataset, and evaluate robustness under newer traffic distributions without turning the undergraduate project into an offensive networking system.
